# The Day in One Picture — Sunday 22 November 2026

This program procedurally draws a broadsheet front page summing up Sunday 22 November 2026's world news as one deterministic 1024×1024 PNG. Run `node main.ts`; it writes `entry.png` to `MAKEFUN_OUTPUT_DIR` or `/output`.
